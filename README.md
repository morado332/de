# معاينة PHP — تطبيق أندرويد لعرض مواقع PHP على الزبائن بدون إنترنت

تطبيق APK يحوّل التابلت إلى سيرفر كامل:
**PHP 8.3 + قاعدة بيانات MariaDB (متوافقة 100% مع MySQL) + متصفح بشاشة كاملة**،
وكل شيء يعمل محلياً على الجهاز بدون إنترنت.

## المميزات

- لكل زبون موقع مستقل، وكل موقع له **قاعدة بيانات ومستخدم وكلمة مرور خاصة فيه**.
- تستورد الموقع كملف **ZIP** واحد، والتطبيق يقوم تلقائياً بما يلي:
  - فك الضغط وتحديد مجلد الصفحة الرئيسية (يدعم مجلد `public` في مواقع Laravel).
  - **قراءة بيانات قاعدة البيانات من ملفات الإعدادات في موقعك** (`config.php` و`wp-config.php` و`.env` و`new mysqli(...)` وغيرها)، ثم إنشاء القاعدة بنفس الاسم والمستخدم وكلمة المرور، حتى يعمل الموقع **بدون أي تعديل في الكود**.
  - إيجاد ملف `.sql` داخل الـ ZIP واستيراده تلقائياً، مع تحويل ترميزات MySQL 8 (`utf8mb4_0900_ai_ci`).
- الاتصال يعمل بكل الطرق: `localhost` (عبر socket) و`127.0.0.1:3306` (عبر TCP)، ومع `mysqli` و`PDO`.
- عرض الموقع بشاشة كاملة مثل موقع حقيقي، مع دعم الروابط الجميلة (pretty URLs) ورفع الملفات والجلسات.
- **Adminer** مدمج لإدارة الجداول (البديل الخفيف لـ phpMyAdmin).
- استيراد ملف SQL في أي وقت، وتفريغ القاعدة، وتحديث ملفات الموقع مع الحفاظ على البيانات.
- إخفاء أخطاء PHP افتراضياً حتى لا تظهر للزبون، ويمكن إظهارها من القائمة وقت التطوير.

## تحميل التطبيق

1. افتح تبويب **Actions** في هذا المستودع، ثم اختر آخر تشغيل ناجح لـ **Build PHP Preview APK**.
2. من قسم **Artifacts** في أسفل الصفحة نزّل:
   - `PHP-Preview-arm64-v8a`: لمعظم التابلتات والأجهزة الحديثة (**ابدأ بهذه النسخة**).
   - `PHP-Preview-armeabi-v7a`: للأجهزة القديمة ذات نظام 32-bit، إذا ظهرت رسالة "الجهاز غير مدعوم".
3. فك ضغط الملف المنزّل، وثبّت ملف الـ APK (اسمح بالتثبيت من مصادر غير معروفة).

> النسخ الجديدة تُثبَّت كتحديث فوق القديمة، والمواقع وقواعد البيانات تبقى محفوظة.

## طريقة الاستخدام

1. على الكمبيوتر اضغط مجلد الموقع كملف ZIP، وضع معه ملف قاعدة البيانات `.sql` المصدَّر من phpMyAdmin.
2. انقل الـ ZIP إلى التابلت (عبر USB أو Google Drive أو تيليجرام...).
3. في التطبيق اضغط **"إضافة موقع زبون جديد"** واختر الملف.
4. راجع البيانات المقترحة (اسم القاعدة، المستخدم، كلمة المرور) ثم اضغط **إنشاء**.
5. اضغط على اسم الموقع ثم **عرض الموقع** وسيفتح بشاشة كاملة.
   زر **⋮** الصغير في الزاوية فيه: تحديث الصفحة، الصفحة الرئيسية، إدارة القاعدة، إغلاق.

### بيانات الاتصال الافتراضية

| | |
|---|---|
| Host | `localhost` أو `127.0.0.1` |
| Port | `3306` |
| root | كلمة المرور **فارغة** (مثل XAMPP)، ويمكن تغييرها من القائمة |
| لكل موقع | قاعدة ومستخدم وكلمة مرور خاصة تظهر في "بيانات الاتصال" |

## ملاحظات

- **WordPress:** الموقع يعمل على `http://127.0.0.1:8080`. إذا كان رابط الموقع في القاعدة `http://localhost/اسم-المجلد`، غيّر `siteurl` و`home` في جدول `wp_options` إلى `http://127.0.0.1:8080` (من Adminer)، أو أضف في `wp-config.php`:
  `define('WP_HOME','http://127.0.0.1:8080'); define('WP_SITEURL','http://127.0.0.1:8080');`
- قواعد `.htaccess` الخاصة بـ Apache لا تُقرأ، لكن كل الطلبات غير الموجودة تُوجَّه إلى `index.php`، وهذا يكفي لمعظم المواقع (Laravel وWordPress وCodeIgniter والمواقع المخصصة).
- إضافات PHP المتوفرة: mysqli, pdo_mysql, pdo_sqlite, sqlite3, mbstring, gd, zip, curl, openssl, xml, dom, simplexml, fileinfo, iconv, bcmath, exif, sodium (إضافة intl غير متوفرة).

## البنية التقنية

- `runtime/build-runtime.sh`: يبني PHP 8.3 وMariaDB 10.11 من حزم Alpine Linux لمعمارية ARM، ويجهّز قاعدة بيانات مُهيأة مسبقاً.
- `runtime/test-runtime.sh`: يختبر التشغيل بنفس طريقة أندرويد (مستخدم عادي، وبدون صلاحيات تنفيذ على الملفات) قبل بناء التطبيق.
- `android/`: كود التطبيق بلغة Java، وبدون أي مكتبات خارجية.
- البرامج تعمل عبر مُحمّل musl (`libldmusl.so`) الموجود في مجلد المكتبات الأصلية للتطبيق، وهذه الطريقة متوافقة مع قيود أندرويد 10 وما بعده.
